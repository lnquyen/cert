## Goal

Replace the old per-cert, arbitrary tab list (`plan`, `d1`...`d5`, `cheat`, `tips`,
`checklist`, `quizzes`, ...) with one fixed 4-tab menu used by every certification:
**How to learn / Lesson / Quiz / Tip**. Core (`core/`) owns the 4 tabs and chrome;
each cert owns its own content styling via a new `certs/<id>/content.css`.

## Gotchas

- **Do not run `git commit` in this project** — the user commits manually.
  (Saved memory: `feedback_no_auto_commit.md`.)
- **`npx serve` breaks this site's relative paths.** `serve`'s default
  "clean URLs" behavior 301-redirects `/certs/cca-f/index.html` →
  `/certs/cca-f` (strips `.html`, no trailing slash added). Since most
  in-page assets are referenced with bare relative paths (`theme.css`,
  `data/nav.js`, not `./theme.css`), losing the trailing slash makes the
  browser resolve them one directory too high → mass 404s
  (`/certs/theme.css` instead of `/certs/cca-f/theme.css`). This reproduces
  even when navigating via the dashboard card click, not just by typing a
  URL by hand. **Fix confirmed working: use `python -m http.server 5500`
  instead.** (An alternative not yet tried by the user: a local
  `serve.json` with `{"cleanUrls": false}` next to `npx serve`.)
- **This machine's shell has `HTTP_PROXY`/`HTTPS_PROXY` pointing at a
  corporate proxy** (`hcm-proxy:9090`) and `NO_PROXY` does **not** exclude
  `localhost`. Plain `curl http://localhost:PORT/...` from the Bash tool gets
  hijacked by a corporate McAfee Web Gateway notification page. Use
  `curl --noproxy '*' ...` to actually reach the local dev server from this
  environment.
- Root dashboard (`index.html`) discovers certs via a hardcoded
  `CERT_IDS = ["cca-f", "itil4-f"]` array and fetches
  `certs/<id>/meta.json` — remember to add any new cert id there too.
